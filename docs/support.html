PinSticky란? / What is PinSticky?

PinSticky는 메모를 화면 위에 띄우고, 필요하면 특정 앱에 종속시켜 해당 앱을 사용할 때만 메모가 나타나도록 돕는 macOS 메뉴 막대 앱입니다.

PinSticky is a macOS menu-bar app that keeps notes floating on screen and can attach notes to specific apps so they appear only when those apps are visible.

주요 기능 / Key Features

  • 여러 개의 플로팅 메모 생성 / Create multiple floating notes
  • 앱별 메모 종속 / Attach notes to specific apps
  • 작은 원으로 접기 / Collapse notes into small dots
  • 메모 검색 및 관리 / Search and manage notes
  • 한국어와 영어 지원 / Korean and English language support

자주 묻는 질문 / FAQ

메모가 갑자기 사라졌어요 / A note disappeared

메모가 특정 앱에 종속되어 있으면, 해당 앱이 화면에 보이지 않거나 최소화되었을 때 메모도 숨겨질 수 있습니다. 앱을 다시 화면에 표시하거나 메모 관리 창에서 종속 상태를 확인해 주세요.

If a note is attached to an app, it may hide when that app is not visible or is minimized. Bring the app back on screen or check the note's pinning status in the note manager.

단축키가 동작하지 않아요 / A shortcut does not work

다른 앱이 같은 단축키를 사용 중일 수 있습니다. PinSticky 설정에서 새 메모 단축키를 변경한 뒤 다시 시도해 주세요.

Another app may be using the same shortcut. Change the shortcut in PinSticky Settings and try again.

메모 데이터는 어디에 있나요? / Where is note data stored?

메모와 설정은 사용자의 Mac 안에 로컬로 저장됩니다. PinSticky는 메모 내용을 외부 서버로 전송하지 않습니다.

Notes and preferences are stored locally on your Mac. PinSticky does not transmit note content to external servers.
