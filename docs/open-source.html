Paperlogy Font

PinSticky는 앱 이름 표시를 위해 Paperlogy 폰트를 포함합니다.

PinSticky includes the Paperlogy font for displaying the app title.

PinSticky uses Apple-provided system frameworks such as SwiftUI, AppKit, and ServiceManagement for macOS app functionality. These frameworks are part of the Apple platform.
