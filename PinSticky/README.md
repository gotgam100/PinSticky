# Pin Sticky Notes

Pin Sticky Notes is a macOS floating note app for keeping app-specific sticky notes above your workspace.

## Features

- Multiple floating sticky notes
- Always-visible notes or notes attached to a specific app
- Auto-save for content, theme, collapsed state, and window frame
- Dot collapse mode with restore animation
- Korean and English UI
- Rich text editing, todo markers, text colors, and line spacing controls
- Deleted note restore history

Open `PinSticky.xcodeproj` in Xcode and run the `PinSticky` scheme.
