# PinSticky

macOS floating sticky note prototype based on `sticky_notes_app_v1_plan.md`.

## Milestone 1

- One always-on-top sticky note window
- SwiftUI editor inside an AppKit floating panel
- Auto-save content, theme, collapsed state, and window frame
- Restore the note on relaunch
- Dot collapse mode
- Built-in color themes inspired by `color_sample.png`

Open `PinSticky.xcodeproj` in Xcode and run the `PinSticky` scheme.
